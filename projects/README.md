# Программная часть разрабатываемого продукта (projects)

В данном каталоге размещается исходный код и архитектурная документация веб-приложения «Интернет-магазин комплектующих для ПК».

## Структура раздела:
- `src/` — исходный код веб-приложения (бэкенд API, веб-клиент, ORM-модели);
- `docs/` — техническая документация по установке, конфигурированию переменных окружения и запуску в Docker.

## Текущий статус:
На этапе выполнения ПЗ № 1–4 ведется аналитическая работа и визуальное моделирование. Разработка программного кода запланирована на последующие практические занятия. В каталогах размещены файлы-заполнители `.gitkeep`.
