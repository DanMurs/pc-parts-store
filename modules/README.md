# Отдельно разрабатываемые модули и библиотеки (modules)

В данном разделе размещаются независимые функциональные модули, проектируемые для изоляции предметной логики интернет-магазина.

## Запланированные модули:
1. `compatibility-checker` — специализированный алгоритмический модуль проверки аппаратной совместимости комплектующих (совпадение сокета CPU и материнской платы, поддержка TDP кулером, соответствие разъемов питания БП и видеокарты, форм-фактор корпуса);
2. `price-importer` — модуль парсинга и валидации прайс-листов поставщиков в форматах CSV/XLSX с нормализацией атрибутов;
3. `notification-dispatcher` — модуль формирования шаблонов писем и асинхронного взаимодействия с внешним SMTP / транзакционным email-шлюзом.

В настоящий момент модули находятся на стадии алгоритмического проектирования.
