# Интернет-магазин комплектующих для ПК

Учебный командный программный проект по дисциплине **«Программная инженерия»**  
**Группа:** ДЭ 25-24

---

## 1. Назначение и цель продукта

Проектируемая система представляет собой специализированную платформу электронной коммерции (интернет-магазин), предназначенную для розничной продажи комплектующих для ПК (процессоры, видеокарты, материнские платы, оперативная память, системы охлаждения, блоки питания, корпуса, SSD/HDD), а также конфигурирования готовых компьютерных сборок.

### Целевые пользователи:
- **Гости:** неавторизованные посетители, изучающие ассортимент, выполняющие фильтрацию и формирующие корзину;
- **Покупатели:** зарегистрированные пользователи с личным кабинетом, историей заказов и персональными скидками;
- **Менеджеры магазина:** сотрудники, контролирующие сборку, резервирование остатков и логистику заказов;
- **Администраторы:** управляющие каталогом товаров, категориями, ценами и пакетным импортом номенклатуры.

---

## 2. Ключевые возможности системы

- Многопараметрический каталог с фильтрацией по совместимости комплектующих (сокет, чипсет, форм-фактор, TDP);
- Быстрое оформление заказов с интеграцией внешнего банковского эквайринга и кассовых чеков;
- Система скидок и промокодов;
- Автоматические email-уведомления о статусах заказов;
- Панель управления для менеджеров и пакетный импорт товаров из форматов CSV/XLSX.
