# Тестирование программного продукта (tests)

Раздел предназначен для хранения сценариев тестирования (тест-кейсов), интеграционных тестов API и сквозных UI-тестов.

## Направления тестирования:
- **Модульное тестирование (Unit Tests):** верификация расчета стоимости корзины, применения промокодов, валидации параметров комплектующих;
- **Интеграционное тестирование:** проверка взаимодействия с эмулятором банковского эквайринга и почтовой службой;
- **Сквозное тестирование (E2E):** проверка пользовательских сценариев от поиска в каталоге до подтверждения заказа.

## Текущее состояние:
Формирование автоматических тестов запланировано синхронно с разработкой модулей в каталоге `projects/src/`.
