## 2. Принятые проектные решения

- **Архитектурный уровень детализации:** Диаграмма последовательностей построена на системном уровне (`:Система`), что исключает преждевременную привязку к внутренним классам и фреймворкам бэкенда на этапе проектирования требований.
- **Взаимодействие со складом:** Резервирование остатков комплектующих выполняется непосредственно перед вызовом платежного шлюза. В случае отклонения транзакции банком система в обязательном порядке отправляет сигнал на снятие временного резерва, что исключает блокировку товарных остатков.
- **Интеграция с промокодами:** Применение купона выделено в опциональный блок `opt`, предшествующий подтверждению оплаты, что строго соответствует связи `<<extend>>` на Use Case диаграмме.
- **Уведомления:** Запрос к почтовому сервису инициируется только после успешного подтверждения транзакции эквайрингом.

## 3. Разработанная диаграмма последовательностей (UC-06)

Диаграмма подготовлена в PlantUML ([исходник](../draw/sd_order_murzakovskiy.puml)):

![Диаграмма UC-06](../img/sd_order_murzakovskiy.png)

### Листинг PlantUML:
```plantuml
@startuml
skinparam style strictuml
skinparam sequenceMessageAlign center
skinparam roundcorner 5

title sd Оформление заказа (UC-06)

autonumber
actor "Покупатель" as Customer
participant ":Система" as System
participant "«External»\nПлатёжная система" as PaymentGateway
participant "«External»\nСистема email-уведомлений" as EmailService

Customer -> System: Перейти к оформлению заказа
activate Customer
activate System
System -->> Customer: Отобразить форму оформления заказа\n(контакты, адрес доставки, способ оплаты)
deactivate System

opt [применение промокода (UC-07)]
    Customer -> System: Ввести промокод
    activate System
    System -->> Customer: Промокод применён (перерасчёт итоговой суммы со скидкой)
    deactivate System
end

Customer -> System: Подтвердить заказ и оплатить (данные доставки и платежа)
activate System
System -> System: Проверка наличия и резервирование комплектующих

alt [A1: товара нет в наличии на складе при резервировании]
    System -->> Customer: Отказ: "Один из товаров закончился на складе. Пожалуйста, скорректируйте заказ"
else [комплектующие успешно зарезервированы]
    System -> PaymentGateway: Запрос на проведение онлайн-платежа (номер заказа, сумма, реквизиты)
    activate PaymentGateway
    
    alt [A2: ошибка авторизации платежа / недостаточно средств]
        PaymentGateway -->> System: Платёж отклонён (код ошибки)
        System -> System: Снятие временного резерва с комплектующих
        System -->> Customer: Сообщение: "Ошибка оплаты. Проверьте баланс карты или выберите другой способ"
    else [платёж успешно проведён (Основной поток)]
        PaymentGateway -->> System: Подтверждение оплаты (идентификатор транзакции)
        deactivate PaymentGateway
        System -> System: Создание заказа со статусом "Оплачен", списание товара со склада
        
        System -> EmailService: Запрос на отправку электронного чека и состава заказа
        activate EmailService
        EmailService -->> Customer: Email-уведомление с кассовым чеком и трек-номером заказа
        deactivate EmailService
        
        System -->> Customer: Сообщение: "Заказ успешно оформлен и оплачен!", трек-номер
    end
end
deactivate System
deactivate Customer
@enduml
```
