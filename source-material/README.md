# Исходные материалы и задания (source-material)

В данном разделе хранятся методические указания, формулировки заданий и справочные материалы по дисциплине «Программная инженерия», предоставленные преподавателем (Храмов Д.Э.).

## Содержимое каталога:
- `ПИ. ПЗ1.docx` — Практическое задание № 1: «Сбор и анализ требований к программному продукту»;
- `ПИ. ПЗ2.docx` — Практическое задание № 2: «Варианты использования (Use Cases)»;
- `ПИ. ПЗ3.docx` — Практическое задание № 3: «Построение и оформление UML диаграмм вариантов использования и последовательностей»;
- `ПИ. ПЗ4. Репозиторий проекта.docx` — Практическое задание № 4: «Организация репозитория командного программного проекта».

Материалы используются командой в качестве эталона требований и регламента оформления отчетности.
